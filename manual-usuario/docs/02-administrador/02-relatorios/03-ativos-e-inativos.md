# Relatório “Ativos e Inativos”

<span className="perfil-tag perfil-adm">ADMIN</span> Menu: **Relatórios → Ativos e Inativos**

## Para que serve
Ver a **situação cadastral** de todos os alunos e a **taxa de retenção**.

## Elementos da tela
<Figura id="REL-03" />

| Elemento | Descrição |
|---|---|
| **Situação** | Filtro: **Todos os alunos**, **Somente ativos** ou **Somente inativos / cancelados**. |
| Indicadores | **Total de alunos**, **Alunos ativos**, **Inativos / Cancelados** e **Taxa de retenção**. |
| Gráfico | Divisão **Alunos Ativos × Inativos / Cancelados**. |
| **Resultado detalhado** | Colunas **Nome, CPF, Situação**; busca por nome ou CPF. |

## Passo a passo
1. Escolha a **Situação**.
2. Clique em **Gerar Relatório**.
3. Consulte indicadores e tabela; exporte se desejar.

## Regras
- “Inativo” significa **desativado logicamente** (*soft delete*): o aluno continua no banco de dados e preserva todo o histórico.

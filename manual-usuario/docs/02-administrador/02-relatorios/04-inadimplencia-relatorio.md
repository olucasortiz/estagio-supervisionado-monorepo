# Relatório de Inadimplência

<span className="perfil-tag perfil-adm">ADMIN</span> Menu: **Relatórios → Relatório de Inadimplência**

## Para que serve
Análise gerencial dos alunos com **situação financeira pendente ou vencida**, para apoiar a cobrança.

## Elementos da tela
<Figura id="REL-04" />

| Elemento | Descrição |
|---|---|
| Indicadores | **Alunos inadimplentes**, **Total no sistema** e **Taxa de inadimplência**. |
| Gráfico | **Em dia (Adimplentes) × Inadimplentes**. |
| Aviso **Atenção** | Lembra o critério usado para classificar a inadimplência. |
| **Resultado detalhado** | Colunas **Nome, CPF, Plano, Situação financeira**; busca por nome, CPF ou plano. |
| **Exportar PDF** | Baixa o relatório. |

## Regra de inadimplência
Um aluno é considerado **inadimplente** quando possui pagamento **Pendente** ou **Atrasado** cuja assinatura **já venceu**. O sistema **não calcula multa nem juros**.

## Passo a passo
1. Abra o relatório e clique em **Gerar Relatório**.
2. Localize o aluno pela busca.
3. Use as informações de plano e situação para a cobrança.
4. Para agir sobre o aluno (registrar pagamento), vá a [Pagamentos](../financeiro/pagamentos).

## Mensagens
- Sem inadimplentes: *“Nenhum aluno inadimplente — Nenhum aluno com pendência na base consultada.”*

# Como funcionam os relatórios

<span className="perfil-tag perfil-adm">ADMIN</span> Menu: **Relatórios**

Os quatro relatórios seguem o **mesmo modelo de tela**:

| Área | Descrição |
|---|---|
| **Cabeçalho** | Título, subtítulo e “trilha” (ex.: *Relatórios › Novos Alunos*). |
| **Filtros da consulta** | Período (Data inicial/final) ou Situação, conforme o relatório. |
| **Gerar Relatório** | Executa a consulta. Durante o processamento o botão mostra **“Gerando…”**. |
| **Indicadores** | Cartões com totais do resultado. |
| **Gráfico** | Resumo visual do resultado (quando aplicável). |
| **Resultado detalhado** | Tabela com **busca** própria para localizar registros. |
| **Exportar PDF** | Gera um arquivo PDF com o resultado exibido. |

## Passo a passo geral
1. Abra o relatório no menu **Relatórios**.
2. Ajuste os filtros.
3. Clique em **Gerar Relatório**.
4. Analise indicadores e tabela; use a busca para filtrar linhas.
5. Clique em **Exportar PDF** para guardar ou imprimir.

## Regras comuns
- Antes de gerar, aparece: *“Revise os filtros, quando disponíveis, e selecione Gerar Relatório para visualizar os dados.”*
- **Exportar PDF** só funciona **depois** de gerar um relatório: do contrário, aparece *“Gere um relatório com dados antes de exportar.”*
- Em relatórios por período, a **data inicial não pode ser posterior à final**, e ambas são obrigatórias.
- Apenas o perfil **ADMIN** acessa os relatórios.

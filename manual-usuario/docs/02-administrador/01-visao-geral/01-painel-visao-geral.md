# Painel “Visão geral”

<span className="perfil-tag perfil-adm">ADMIN</span> <span className="rota">/dashboard</span> · Menu: **Visão geral**

## Para que serve
Dar, em uma única tela, o retrato da academia: quantos alunos há, como está a receita e o que aconteceu recentemente. Apoia a tomada de decisão do gestor.

## Elementos da tela

<Figura id="ADM-01" />

| Bloco | O que mostra |
|---|---|
| **Indicadores da academia** | Cartões com totais: alunos cadastrados, ativos, inativos, inadimplentes, pagamentos e cancelamentos. Os números “contam” até o valor final ao abrir a tela. |
| **Receita mensal** | Gráfico de **pagamentos agrupados nos últimos seis meses**. Os botões com o nome dos meses, abaixo do gráfico, servem de eixo: toque em um mês para ver o valor daquele período no topo do gráfico. |
| **Receita por plano** | Estimativa de participação de cada plano, a partir das assinaturas vinculadas. Sem planos: *“Nenhum plano cadastrado.”* |
| **Registros recentes — Pagamentos** | Tabela com Aluno/Assinatura, Método, Valor, Data e Situação. Sem dados: *“Nenhum pagamento registrado ainda.”* |
| **Registros recentes — Personal trainers** | Tabela com Profissional, Especialidade, Contato e Situação. |
| **Atividades recentes** | Linha do tempo de cadastros e movimentações. Sem dados: *“Nenhuma atividade registrada ainda.”* |

<Figura id="ADM-02" />

## Passo a passo
1. Entre com seu usuário administrador.
2. Leia os cartões de indicadores no topo.
3. Role a tela para ver receita mensal, receita por plano e registros recentes.
4. Para detalhar qualquer número, abra a tela correspondente no menu (ex.: inadimplentes em **Financeiro → Inadimplência**).

## Regras
- Os indicadores são **calculados a partir dos dados cadastrados** — não há valores digitados à mão.
- Apenas o perfil **ADMIN** acessa este painel.

:::tip[Dica]
Se um número parecer estranho, confira a tela de origem (Alunos, Pagamentos…) e os filtros aplicados.
:::

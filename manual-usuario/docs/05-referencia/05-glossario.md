# Glossário

| Termo | Significado |
|---|---|
| **ADMIN** | Perfil administrador: gestão completa. |
| **PERSONAL_TRAINER** | Perfil do personal: alunos vinculados e fichas. |
| **OPERATIONAL** | Perfil do aluno: consulta dos próprios dados. |
| **Assinatura** | Vínculo entre aluno e plano, com início, término e status. |
| **Vigência** | Período em que a assinatura vale. |
| **Inadimplente** | Aluno com pagamento Pendente/Atrasado e assinatura vencida. |
| **Soft delete / inativar** | Desativar sem apagar do banco de dados. |
| **Ficha de treino** | Conjunto de exercícios prescritos para um aluno em um dia da semana. |
| **Catálogo** | Biblioteca interna de exercícios. |
| **Exercício personalizado** | Exercício criado por um personal, fora do catálogo padrão. Só quem criou (ou o administrador) pode editá-lo. |
| **Avaliação física** | Registro opcional de medidas do aluno (peso, altura, perímetros, dobras ou bioimpedância, sinais vitais e PAR-Q). |
| **PAR-Q** | Questionário de prontidão para atividade física, com 7 perguntas Sim/Não. Um “sim” recomenda liberação médica. |
| **IMC** | Índice de massa corporal: peso ÷ altura², classificado pelas faixas da OMS. |
| **RCQ** | Relação cintura-quadril: cintura ÷ quadril; indicador de risco cardiovascular. |
| **Dobras cutâneas (Pollock)** | Medidas de gordura sob a pele (em mm) usadas pelas equações de Jackson & Pollock para estimar o % de gordura. |
| **Carga por aparelho** | Peso usado em uma série de um exercício, anotado pelo aluno durante o treino. |
| **JWT** | Token de segurança gerado no login. |
| **BCrypt** | Método de criptografia das senhas. |
| **Pix** | Pagamento instantâneo por QR Code ou código copia e cola. |
| **Mercado Pago** | Provedor usado nos pagamentos online (ambiente de testes). |
| **CRUD** | Criar, consultar, atualizar e excluir/inativar. |

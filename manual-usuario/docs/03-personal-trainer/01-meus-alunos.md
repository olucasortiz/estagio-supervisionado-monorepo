# Meus Alunos

<span className="perfil-tag perfil-pt">PERSONAL_TRAINER</span> Aba **Meus Alunos**

## Para que serve
Encontrar um aluno vinculado a você e **continuar a prescrição do treino** — *“Encontre um aluno e continue a prescrição do treino.”*

## Elementos da tela
<Figura id="PT-01" />

| Elemento | Descrição |
|---|---|
| **Buscar aluno** | Procura por **nome ou CPF**. |
| **Situação do aluno** | Filtro **Todos · Ativos · Inativos**. |
| Tabela | Colunas **Aluno, Situação, Ficha ativa, Treino**. Em telas pequenas, os dados viram cartões com CPF, Situação e Ficha ativa. |
| **Gerenciar ficha** | Abre as fichas daquele aluno. |
| **Conversar com (nome)** | Abre o chat com o aluno. |
| **Tentar novamente** | Aparece se a lista falhar ao carregar. |

## Estados da lista
- *“Carregando lista de alunos…”*
- *“Nenhum aluno encontrado — Ajuste a busca ou os filtros.”*
- *“Nenhum aluno está vinculado ao seu perfil no momento.”* — peça à administração para vincular alunos a você (etapa **Personal** do cadastro de aluno).
- *“Não foi possível carregar a lista de alunos.”*

## Passo a passo
1. Digite o nome ou CPF em **Buscar aluno** (opcional).
2. Escolha **Ativos**, **Inativos** ou **Todos**.
3. Clique em **Gerenciar ficha** para prescrever ou **Conversar** para falar com o aluno.

<Figura id="PT-12" />

## Regras
- Você vê **apenas alunos vinculados** a você.
- Só é possível criar fichas para os **seus** alunos.

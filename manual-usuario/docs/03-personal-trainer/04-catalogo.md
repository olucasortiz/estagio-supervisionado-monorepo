# Catálogo de exercícios (visão do personal)

<span className="perfil-tag perfil-pt">PERSONAL_TRAINER</span> Aba **Catálogo**

## Para que serve
Consultar a biblioteca de exercícios disponíveis para prescrição, com filtros de busca. A tela é a mesma do administrador: veja os detalhes em [Catálogo de Exercícios](../administrador/cadastros/catalogo-de-exercicios).

## Como usar
1. Abra a aba **Catálogo**.
2. Use **Filtros de busca** (nome, categoria, músculo, equipamento) e **Situação**.
3. Consulte a tabela **Biblioteca de exercícios** (**Nome, Categoria, Músculo, Equipamento, Origem, Situação**).

## O que você pode alterar
- Exercícios **padrão** do catálogo aparecem como **Somente consulta**.
- **Novo exercício** cria um exercício **personalizado**, vinculado a você.
- Exercícios **personalizados criados por você** podem ser **editados** (nome, categoria, músculo, equipamento e instruções) e **ativados ou inativados**.

:::info[Fichas já montadas]
Editar um exercício vale para as **próximas prescrições**. As fichas já salvas guardam a cópia do exercício como estava.
:::
